Privacy Policy

Last updated: August 2026

1. Data Collection and Storage

Opinova is designed as a local-first application. All data, including feedback files (CSV), generated clusters, logs, and database records (SQLite), are stored strictly locally on your machine. We do not transmit your data to any external or cloud servers.

2. AI Processing

Opinova utilizes a local or securely configured Language Model (LLM) processing pipeline. If configured to use local models, no data leaves your machine. If configured to use external API providers (e.g., OpenAI, Google), the data processing will be subject to the respective provider's privacy agreements.

3. Activity Logs

We maintain local activity logs to help you monitor system actions such as file uploads, report generation, and database synchronizations. These logs are stored in your local directory and can be cleared at any time from the Settings menu.

4. Contact Us

If you have any questions about this Privacy Policy, please refer to the project documentation or contact the administrator of your Opinova deployment.

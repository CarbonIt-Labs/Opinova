Installation & Setup Guide

Getting Started with Opinova

Follow these steps to deploy and configure the Opinova Decision Intelligence platform on your Windows machine.

1

Installation

Download Opinova_Setup_x64.exe, run the installer, and follow the on-screen steps. Once installation is complete, launch Opinova.

2

Default Login

On the first launch, sign in using the default administrator account. For security, please change these credentials after logging in.

User ID: admin
Password: admin123
3

Get a Gemini API Key

Opinova uses the Gemini API for its AI-powered analysis and summaries. Open Google AI Studio, navigate to the API Keys section, create a new key, and copy it.

4

Configure & Secure Opinova

Inside Opinova, open Settings from the left-side menu. Complete the following two steps:

  • Find Enter Gemini API key, paste your copied key, and save/apply the settings.
  • Open the Default Login section to change your User ID and Password for future logins.

Structured Quick Start Guide

Follow these steps to deploy and utilize the Opinova Decision Intelligence platform locally on your machine.

1

Prerequisites & Installation

Ensure Python 3.10 or higher is installed on your system. Clone the official CarbonIt Labs repository and install the required dependencies.

git clone https://github.com/CarbonIt-Labs/Opinova.git
cd Opinova
pip install -r requirements.txt
2

Initialize Application

Start the application using the main entry script. This will boot the local backend engine and launch the pywebview desktop container interface.

python startapp.py
3

Authentication

Upon launch, you will be prompted with a login screen securing your local database. Use the default developer credentials to proceed.

User ID: admin
Password: admin123
4

Analyze Data

Inside the dashboard, navigate to the Upload CSV section. Select your unformatted feedback data file and click Analyze to trigger semantic clustering and priority scoring.
